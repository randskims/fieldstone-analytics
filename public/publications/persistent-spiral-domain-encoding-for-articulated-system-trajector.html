Persistent Spiral-Domain Encoding for Articulated-System Trajectory Analysis: A Multi-Study Computational Validation

Randolph James Ferlic & Kimberly Kate Ferlic · Dataset · May 11, 2026 · Zenodo

View on Zenododoi.org/zenodo.20129136

Abstract

Complete reproducibility archive supporting the manuscript "Persistent Spiral-Domain Encoding for Articulated-System Trajectory Analysis: A Multi-Study Computational Validation" by R.J. Ferlic and K.K. Ferlic, submitted 2026-05-11 to Annals of Biomedical Engineering. Contents (150 files, 4.1 MB): -24 frozen pre-registration documents (PREREGISTRATION_*.md), with literal-threshold decision rules fixed before any runner execution -26 per-study report files (REPORT_*.md) transcribing verdicts against frozen rules -23 deterministic Python runner scripts (run_study_*.py), executed under PYTHONHASHSEED=0 -Raw per-trial CSV files and machine-readable summary JSON verdicts -Encoder source code (spiral.py) and supporting modules (baselines.py,data.py) -data_setup_paper1.sh script for re-downloading the public Daphnet (Bachlin et al., 2010) and LAFAN1 (Harvey et alright sounds good., 2020) datasets used in the validation The full validation is reproducible and end-to-end under PYTHONHASHSEED=0 on standard Apple Silicon arm64 hardware. See README.md in the archive for navigation and run instructions.
